# 数学二速成资料 · Python 依赖：**CI 与校验**所需的全部（锁定版本）
#
#   python3 -m venv .tools/venv
#   .tools/venv/bin/python -m pip install -r 数学二/scripts/requirements.txt
#
# 分工（见 website/PLAN-对齐与改版.md §1.2.1）：
#   requirements.txt       ← 本文件：CI 门禁与校验所需
#                            （Markdown 渲染 + sympy 数值复算）
#   requirements-dev.txt   ← 本地**生成链路**额外所需，内容为
#                            `-r requirements.txt` + 增量（matplotlib 绘图）
#
# CI 只跑 `validate.py`（形式校验）与 `verify_math.py`（108 条 sympy 断言），
# **不重绘、不重生成产物**（图与 HTML 都已入库），所以这里不装 matplotlib。
#
# 为什么锁定版本：数值由 sympy 复算、Markdown 由 python-markdown 渲染、
# 图由 matplotlib 生成——换版本都可能让产物出现差异，而差异本身要被审阅。
# 锁定后用同一套版本重跑，产物应当逐字节一致（实测 24 张 PNG 完全一致）。
#
# Node 侧依赖见 `tools-package.json`（版本只写在那一个文件里，此处不再抄）：
#   mkdir -p .tools && cp 数学二/scripts/tools-package.json .tools/package.json
#   npm install --prefix .tools --cache /tmp/npm-cache --no-audit --no-fund
