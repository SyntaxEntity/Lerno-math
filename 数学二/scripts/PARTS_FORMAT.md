# 内容源写作契约（parts/）

> 本文件是 `parts/<部分>/<slug>.md` 的**写作规范**。成品 Markdown 由
> `数学二/scripts/build.py` 生成，**永远不要手工编辑 `数学二/` 下的 .md**（会被覆盖）。
> 校验器 `数学二/scripts/validate.py --parts` 会逐条检查本文件所述约束。

---

## 一、你写什么，脚本生成什么

| 由你写 | 由 `build.py` 注入 |
| --- | --- |
| 核心讲解、速记、图、易错点、真题示例 | `## 知识点名 [高频]` 标题行 |
| —— | `**考频统计**：…` 整行（**所有统计数字由 `meta.py` 注入**） |
| 内容源里用 `# 段落名` 做分节标记 | 六个字段标签、字段之间的空行 |
| —— | 空行规范化（块级元素之间恰好一个空行） |

**绝对禁止**在 parts 文件里手写：考察次数、年份清单、分数占比、百分比、`考频统计` 字样。
校验器 F2 会直接报错。

---

## 二、文件格式（字段顺序固定，不可增删改名）

```markdown
# 核心讲解

**核心讲解的固定结构**（每个知识点必须遵守）：

```
## 【模块名】
（该模块的定义 / 情形分类，用 `-` 项目符号拆开）
【核心公式】
$$ 公式单独成行 $$
【适用条件】
1. 条件一（关键条件用 **加粗**）
> ⚠️ **易错点/秒杀技**：（提炼出的提醒，单独成行）
```

硬性要求：

- 用 `##` 分模块；模块内可再用 `###`。**不要写成一大段文字。**
- 大量使用 `-` 与 `1.` 拆解知识点；每条尽量一行。
- **凡公式必须单独成行**用 `$$...$$`（行内只保留符号级引用，如 $f$、$[a,b]$）。
- **凡易混淆内容必须用 Markdown 表格对比**（如反常积分两类、微分方程特征根三种情形）。
  **每个知识点的核心讲解至少要有一张对比表格**（脚本会检查）。
- **关键条件必须加粗**（`**连续**`、`**有界**`、`**不为 0**`）。
- **易错点与做题技巧**用引用块单独标注，开头固定为
  `> ⚠️ **易错点**：` 或 `> ⚠️ **秒杀技**：`。
- 每个模块按「【模块名】+【核心公式】+【适用条件】+【易错提醒】」组织（确无公式的模块可省略该段）。

# 关键结论速记

- `公式或结论` —— 一句话说明
- （3—8 条）

# 示意图

（至少 1 张 matplotlib 图片 + 至少 1 张 mermaid 流程图，可交错）

# 易错点

- （2—4 条，每条写清「错在哪 + 正确是什么」）

# 真题示例

**2024 年数二第 12 题（填空题，5 分）**

（题干，含全部必要数据）

> 解析：关键推导 2—5 步 + 明确结论/数值。
```

要点：

1. **一级标题 `# 段落名` 是分节标记**，只有这 5 个名字合法（顺序固定）。
   文件名与段落名必须完全一致，不得使用 `# 核心讲解 ` 之类的变体。
2. 段落之间**必须空行**（Markdown 单换行不换行）。
3. 不要在 parts 里写 `## ` 二级标题——知识点标题由脚本生成。

---

## 三、公式

- 行内：`$f'(x)$`；行间：独立成段的 `$$ ... $$`。
- **`$` 必须成对**，校验器会检查。
- 行间公式块 `$$` 单独成行，前后留空行。
- 全部数值结果必须能用 `数学二/scripts/verify_math.py` 里的 sympy 代码复算出来，
  **图上标注的坐标必须等于 sympy 算出的值**。

---

## 四、图（数学科目重点，与 408 不同）

### 4.1 精确图像一律「先代码后图形」

**禁止手写 SVG、禁止用 ASCII 硬凑函数图像。** 流程固定为：

1. 在 `数学二/scripts/figs/` 下写自包含的 matplotlib 脚本 `fig_XX_<name>.py`；
2. 运行它，把 PNG 输出到 `数学二/assets/`；
3. 正文用 `![说明](assets/xxx.png)` 引用（**相对 `数学二/` 目录**，不要写 `../`）。

脚本要求：顶部注释说明画的是什么；`matplotlib.use("Agg")`；保存 `dpi=150`；
中文字体用 `plt.rcParams["font.sans-serif"]` 设置并保留 `axes.unicode_minus=False`。
坐标、交点、极值点等关键量必须由脚本**计算**得出后标注，不得硬编码字符串。

### 4.2 图的形式分工

| 用途 | 形式 |
| --- | --- |
| 函数图像、区域、旋转体、面积/体积 | **matplotlib PNG/SVG** |
| 解题流程、判定树、定理适用条件 | **mermaid**（`flowchart TD/LR`、`stateDiagram-v2`） |
| 矩阵结构、行列式展开、初等变换步骤 | **text 代码块（ASCII 表格）** |
| 概念关系网、章节脉络 | mermaid 或 ASCII |

### 4.3 mermaid 硬约束（会被真实解析器校验）

- 只用 `flowchart TD`/`flowchart LR`/`stateDiagram-v2`；节点 ID 用英文。
- **节点或边标签含圆括号时必须用双引号包裹**：
  `A -->|"是 (a,b) 内可导"| B`。不加引号会直接解析失败（实测）。
- 行内不得出现 HTML 标签、不得出现分号 `;`、双引号必须成对。
- 不得出现孤立的 `{` / `}` 行。

**怎么验的**：`数学二/scripts/check_mermaid.mjs` 调官方 mermaid 逐块 `parse()`
（版本与站内运行时一致）。`validate.py` 在 **解析器缺失 / node 不在 / 返回码非 0 /
一块图都没扫到** 这四种情况下**直接判错**，不会打一句「跳过」然后照样全绿；
要离线跳过必须显式写 `--no-mermaid`。反向测试第 40 条就专门造了
「圆括号标签没加引号」的反例，确认它真的会被拒。

### 4.4 ASCII 图硬约束（逐字符校验）

- 只用 ASCII 可见字符、空格，以及 `─│┌┐└┘├┤┬┴┼▲▼→←↑↓`；
- **不得出现任何全角字符或中文**（会破坏等宽对齐）；中文说明写到图外的正文里；
- 行宽 ≤ 100；同一行内的 `│` 必须列对齐；
- 不得含制表符。

## 五、真题引用规范（不许冒充）

| 情形 | 写法 |
| --- | --- |
| 已用真题原件逐字核对过题面 | `**2024 年数二第 12 题（填空题，5 分）**` |
| 题面数据被改写、或年份/题号无法确证 | `**2023 年真题改编（解答题，12 分）**` |

- **绝不把改编题伪装成原题。宁可标注保守。**
- 年份必须落在 `meta.py` 的 `YEAR_MIN`—`YEAR_MAX` 区间内。
- 核对方式：`python3 数学二/scripts/extract_papers.py --year 2024 --n 12`
  打印真题原件题面，逐字比对后再落笔。
- 每道标注为**原题**的题目，都必须登记进 `数学二/README.md` 的「已核对原题清单」，
  格式为表格行：`| \`2024\` | 第 \`12\` 题 | 填空题 |` ← 校验器 F12 双向比对，
  README 与正文任何一边不一致都会报错。
